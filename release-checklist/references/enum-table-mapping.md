# 枚举-数据库表映射

当枚举类新增枚举值时，需检查本文件中的映射关系，判断是否需要同步生成对应的 DML。

## 映射表

| 枚举类 | 关联表 | DML 模板 | 说明 |
|--------|--------|----------|------|
| `MsgTypeCodeStatus` | `sys_notify_type` | `INSERT IGNORE INTO sys_notify_type (code, name, type) VALUES (<code>, '<name>', <type>);` | 新增消息类型时必须插入，否则用户无法在通知设置中看到该选项。`code` 和 `name` 取枚举值，`type` 需根据业务场景确定（当前委托相关通知 type=5） |

## 使用方式

1. 在 Phase 3（分析数据库变更）中，检测到上表中的枚举类有新增值时，直接生成对应 INSERT 语句
2. 如果 DML 模板中有无法从代码推断的字段（如 `type`），参考同枚举中相邻枚举值的已有数据推断，或标注 [待确认]
3. 生成的 DML 使用 `INSERT IGNORE` 以确保幂等性

## 维护说明

> 此表可能不完整。当发现新的枚举-表映射关系时，请补充到本文件中。
> 常见信号：枚举新增值后运行时报"找不到配置"或功能不生效，通常意味着存在未记录的映射关系。
